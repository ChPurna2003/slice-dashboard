# 🚀 Slice Ops War Room – Live Performance Dashboard

**A real-time team and agent performance monitoring dashboard designed to improve productivity, transparency, and healthy competition across operations teams.**

🌐 **Live Demo:** https://slice-dashboard.onrender.com

---

## 📌 Overview

Slice Ops War Room is a web-based live operations dashboard designed to monitor and visualize agent performance, team productivity, call activity, and approval metrics in a centralized interface.

The dashboard transforms operational data into meaningful visual insights, helping team leaders and managers monitor performance, identify top performers, track inactive agents, and encourage healthy competition between teams.

Built with an emphasis on simplicity, visibility, and performance, the dashboard is suitable for large office displays and operational monitoring environments.

## ⚙️ System Architecture

The dashboard follows a simple data-processing architecture:

1. Operational data is maintained in an Excel workbook.
2. The Node.js backend reads and processes the Excel data.
3. Express.js exposes the processed information through an API.
4. The frontend retrieves the dashboard data.
5. JavaScript updates the performance metrics and visual components.
6. The dashboard refreshes to reflect the latest available data.

**Architecture Flow:**

Excel Data → Node.js → Excel Processing → Express API → Dashboard UI → Live Monitoring
